# The Zanzibar compliance pack is P0, but only for Zanzibar properties

ZRA forbids a PMS supplier from onboarding a Zanzibar property unless every booking channel is integrated and reported to ZAN Gateway, and treats manual or delayed OTA data as non-compliant (ZAN GW guide §3.3, §3.5). Zanzibar is a first-launch market, so ZAN Gateway reporting, VFMS fiscal receipts and channel connectivity are P0 for any property under the Zanzibar jurisdiction profile. Mainland properties do not need them in P0, and OTA connectivity elsewhere follows the normal release plan.

## Considered Options

- Keep Zanzibar out of P0 and launch on the mainland only. Rejected because Zanzibar is a first-launch market.
- Put OTA connectivity into P0 for every property. Rejected because only Zanzibar's rules require it.
